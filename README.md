# Two-Sentence Horror

A two-sentence horror story — my entry for the [make.fun](https://make.fun) bounty **u-suroto-two-sentence-horror-acea9253**. Exactly two sentences, under 400 characters, built to linger long after the second sentence lands.

> When my wife died, I kept her side of the bed empty out of respect. Last night I woke to the mattress dipping beside me, and a voice I thought I would never hear again whispered, "It's so cold in the ground — move over."

## Run

```bash
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints the same text to stdout.
